# Sound effects library

The unused files from the Kenney UI Audio pack (CC0, kenney.nl). They are kept
here so they aren't deployed: `scripts/build-pages.mjs` only copies `assets/`.

To use one, move it into `assets/audio/sfx/` (or `assets/audio/loop/` for looping music and ambience) and add it, with that folder in its src, to `js/sound-config.js`.
